# Code of Conduct

## Our commitment

We are committed to making participation in this project a respectful, welcoming, and harassment-free experience for everyone, regardless of background, identity, experience level, or role.

## Expected behavior

Examples of behavior that contributes to a positive community include:

- being respectful and constructive in technical discussions
- giving and accepting feedback professionally
- focusing criticism on ideas and code rather than people
- respecting differing levels of experience and perspective
- helping keep issues and pull requests useful and on topic

Unacceptable behavior includes harassment, discriminatory or insulting comments, personal attacks, deliberate intimidation, or publishing another person's private information without permission.

## Scope

This Code of Conduct applies in project spaces, including issues, pull requests, discussions, reviews, and other public interactions representing the project.

## Enforcement

Project maintainers may edit, remove, reject, or close contributions and interactions that violate this Code of Conduct, and may restrict participation when necessary to protect the community.

If you need to report a conduct concern, contact the project maintainer through the maintainer's GitHub profile rather than posting sensitive details publicly.

## Spring ecosystem

When participating in Spring project spaces, contributors must also follow the Spring Code of Conduct and the rules of the relevant Spring project.
